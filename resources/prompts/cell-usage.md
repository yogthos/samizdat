Actions: list, show {name, version?}, save {name, clj | file, rationale}, versions {name}, revert {name, version, rationale}, diff {name, from?, to?}. A cell is one step of the loop, as Clojure. Save validates by compiling the loop and dry-running it before it stores, and stores a new VERSION in this project — the shipped template is never written. For a large body, write it to a file first (write_file), then save {name, file}: a fix left as a file and never saved does not exist. rationale: one sentence on why — the history shows it to the next supervisor deciding whether your change stays. diff: what changed between two versions (the newest and the one before it by default), named by the form, clause and binding it lives in.
